How Scaling Works:
Real distances: Sun to Neptune = 60 billion km. Real diameters: Jupiter = 140,000 km, Mercury = 4,879 km.
Problem: If drawn to true scale, planets would be invisible specks.
Solution (Logarithmic Scaling): We use log₁₀(diameter) to scale sizes. This makes small planets visible while still showing relative differences. Distances are scaled proportionally so orbits remain accurate.
Result: You can see both tiny Mercury AND massive Jupiter on same view.
