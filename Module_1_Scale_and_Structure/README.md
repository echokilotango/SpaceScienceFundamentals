# Space Science Fundamentals

This repository contains educational materials developed for Space Science Fundamentals training.

## Module 1: Scale & Structure of the Universe

### Contents
- 📄 Research Document - Module 1.pdf
  - Executive summary
  - Cosmic hierarchy
  - Distance units
  - Quick facts
  - Discussion questions
  - Research sources

- 📊 Cosmic_Scale.pptx
  - Presentation slides for instructional delivery

- 💻 cosmic_scale_walk.py
  - Python activity demonstrating the scale and structure of the universe through a powers-of-ten visualization.

## Objectives
- Understand astronomical distance units (km, AU, ly, pc)
- Explore the cosmic hierarchy from Earth to the observable universe
- Develop intuition for orders of magnitude in astronomy
- Use computational tools to visualize cosmic scales
